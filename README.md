# 巴利语学习 App：备份技术原型 01

这是一个用于 Android Chrome 实机验证的最小 PWA 原型，不是完整学习 App。

## 当前验证范围

- IndexedDB 保存模拟 Learning 与 Settings。
- 通过 File System Access API 选择/创建 `.palbackup` 文件。
- 对同一个文件重复写入完整快照。
- 写入后重新读取并用 SHA-256 校验。
- 从已选文件恢复数据。
- 清除本原型 IndexedDB，模拟清除网站数据后通过文件选择器重新导入。
- File System Access API 不可用时，可下载备份文件并通过文件选择器恢复。

## 运行

PWA 和 Service Worker 需要 HTTPS 或 localhost。将整个目录部署到支持 HTTPS 的静态托管服务，或在电脑本地启动静态服务器后通过手机访问。

不要直接用 `file://` 打开 `index.html`，否则 Service Worker、PWA 和安全上下文 API 无法完整工作。

## Android 实机测试步骤

1. 用 Android Chrome 通过 HTTPS 打开部署地址。
2. 添加 3 条以上模拟学习记录，并修改设置。
3. 点击“选择 / 创建备份文件”，保存为 `Pali_Learning_Test.palbackup`。
4. 点击“写入并验证快照”。
5. 再添加记录、修改设置，再次点击“写入并验证快照”。
6. 点击“读取并验证文件”，确认校验成功。
7. 点击“从备份恢复”，确认数据一致。
8. 再次添加记录并备份。
9. 点击“模拟清除本地网站数据”。这只删除本原型 IndexedDB，不会删除备份文件。
10. 使用“选择备份文件恢复”手动选择之前的 `.palbackup` 文件，确认可以恢复。
11. 关闭 Chrome、重新打开；再重启手机后重复文件读写测试。
12. 另行通过 Chrome 设置清除此网站的数据，再验证文件句柄丢失后能否重新选择文件恢复。

## 已知限制

- 文件句柄存储在 IndexedDB 中；清除网站数据后句柄会丢失，必须重新选择文件。
- 浏览器权限可能被撤销，可能需要重新授权。
- PWA 不保证关闭后后台定时执行备份。
- Android 文件提供者对写入、替换、同步的行为可能不同。本原型使用 `createWritable()` 写入同一文件，并在关闭后重新读取校验；这不是对原子写入的保证。
- 原型没有实现双文件轮换或数据库事务级的生产恢复保护；测试阶段不要将唯一重要数据交给它。
- 此原型没有包含正式词汇内容库、卡片学习 UI、复习状态机或正式版本迁移。

## 重要安全提示

本原型仅用于测试。测试期间请保留模拟数据，不要导入真实且不可替代的个人学习记录。正式版本必须在写入策略、失败恢复、权限恢复和实际 Android 设备测试通过后再启用自动外部备份。
